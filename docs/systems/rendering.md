# Rendering

**Status:** Implemented  
**Owner:** `crates/renderer`  
**Source:** [Renderer](../../crates/renderer/src/lib.rs), [mesh contract](../../crates/mesh/src/lib.rs), [diffuse shader](../../crates/renderer/src/shader.wgsl)

## Purpose and boundary

Rendering turns a list of mesh instances into a perspective image on a supplied window. It owns GPU device, surface, pipeline, buffers, depth target, camera uniform, and presentation. [Windowing](windowing.md) owns the window lifecycle and calls the renderer at event boundaries. Mesh creation belongs to producers such as the engine primitive module or future asset importers.

## State and invariants

Each `MeshInstance` stores a mesh and a `Transform`. `Renderer` validates the supplied instances, applies transforms to positions and normals, flattens them with per-instance index offsets, and uploads that geometry during initialization. `update_instances` rewrites transformed vertices when instance topology is unchanged. The assigned `Camera` supplies view, projection, and clear-color state; assigned directional lights supply the diffuse lighting array. `update_camera` and `update_lights` write those changes to the uniform and render target. The surface configuration, depth target, and camera aspect match the most recent nonzero window size. The renderer supports one graphics API per instance through `GraphicsApi`; Vulkan is the default. Window mode changes do not change the renderer's API.

The current example contains a white plane, red cube, and green UV sphere generated by the engine primitives module. The cube rotates and the sphere moves between two points using the math interpolation helpers. A right-handed perspective camera looks toward them. The WGSL shader combines ambient light with assigned directional lights. Depth testing and back-face culling preserve the solid shapes. A second screen-space UI pass draws the debug panel and sliders over the scene.

## Public contract

`Renderer::new` accepts a nonempty slice of `MeshInstance` values and a window surface supported by the selected graphics API. `update_instances` accepts changed transforms while preserving vertex and index counts. `Mesh` producers use the shared vertex and triangle-index contract; primitive generation is outside the renderer. `resize` ignores zero dimensions. `render` draws and presents one frame or reports an error.

`GraphicsApi` maps Vulkan, DirectX 12, OpenGL/GLES, and Metal to wgpu backends. Selecting an unavailable API returns an adapter error rather than silently switching APIs.

## Lifecycle

The renderer creates its GPU resources during window resume and drops them on suspension. On resize it reconfigures the surface, recreates the depth target, and updates camera projection. On an outdated surface it reconfigures; on a lost surface it recreates the surface; on timeout or occlusion it skips a frame.

## Verification and open questions

`cargo test --workspace --offline` and `cargo clippy --workspace --all-targets --offline -- -D warnings` passed on Windows. The geometry test checks outward triangle winding. Windowed, borderless, and exclusive-request runs initialized Vulkan and presented a first frame. DirectX 12 also presented a first frame. Pixels, OpenGL, Metal, native exclusive mode, and non-Windows platforms have not been directly inspected in this environment.
